# Free MAIN paired experiment protocol

Freeze the audited source commit in detached isolated checkouts. Give two fresh MAINs identical compact-audit task acceptance, neutral catalog/tool/context facts, frozen aggregate history and unknown quota. Give only the treatment MAIN an advisory Jev reference; preserve the original request provenance and reused-call timestamp. Keep MAIN prompts identical except paths and that reference. Do not feed either MAIN historical reports or fixtures.

Both MAINs may execute directly or choose terminal workers. Where MAIN runtime lacks a spawn tool, provide the same real caller transport bridge to both: MAIN writes a request containing action `WAITING_HANDOFF` and requests with `request_id`, `model_selector`, `owned_paths`, and `task_prompt`, then yields `WAITING_HANDOFF`. Contracts use Task / Return / Constraints, explicit models, disjoint owned output paths, bounded objectives, acceptance checks and no subdelegation. MAIN may continue independent work before yielding. Caller validates allowed models/path boundaries, physically spawns exactly requested contracts, and resumes the same persistent MAIN with paths/status/results. Caller makes no model-selection or acceptance decisions. No standalone selector inference is added; ordinary MAIN continuation and worker usage still counts.

Allow one level, at most two total terminal spawn attempts, including at most one replacement for a non-started availability failure. MAIN chooses any replacement and integrates/accepts evidence. Direct execution is valid even when the bridge is available. Continuations are one execution episode, not task retries. Requested time/token budgets are not hard guarantees. Record whether the bridge was merely available or actually exercised.

After completion, randomize anonymous labels; copy only reports, probes and explicitly necessary reproduction dependencies. Preserve originals/hashes and findings; substitute identity paths and exclude documented process/billing/decision metadata. Block remaining identity contamination. Independent terminal judges see only their sample, frozen source and original task criteria; reproduce findings and return bounded acceptance evidence. Keep mapping and manifests private. Capability-limited trials remain separate unjudged setup, not outcome failures.

Collect only manifest-listed scalar token events and metadata model names, with exact filename/metadata identity checks. Deduplicate request events using cumulative boundaries and reconcile sums with final totals. Never export IDs, private paths, prompts, conversation/provider state or credential errors. Publish per-request scalar records and rates; replay `(uncached input × input rate + cached input × cache rate + output × output rate) / 1e6`. Input includes cache; do not add reasoning to output. Apply tiers per request; retain null unknown components. Report MAIN, judge, superseded setup and preparation phases separately; preparation remains a dated partial snapshot until refreshed. Allocate a reused Jev call once and label any input-only proxy separately from invoice cost.

State the routing evidence precisely: a manually adapted production-built request template sent through production post/parse/advisory functions is a partial semantic-plus-facts check, not a full route invocation. Do not invent a route ID or fresh builder call. A later policy commit used as the documentation base does not change the experiment's frozen source or establish policy causality. One observation, especially with zero handoffs or child model choices, cannot demonstrate model-diversity improvement or guarantee outcomes/costs.
